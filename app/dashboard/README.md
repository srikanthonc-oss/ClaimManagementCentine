# Dashboard Page

The Dashboard page provides a comprehensive overview of claims processing metrics, displaying key performance indicators and statistics across multiple dimensions.

## Features

- **Real-time Metrics**: Displays up-to-date statistics about claims processing
- **Auto-refresh**: Automatically refreshes data every 30 seconds
- **Comprehensive Views**: Shows metrics grouped by:
  - Overview (total, pending, approved, denied claims)
  - Financial metrics (total billed, average billed, average days aged)
  - Platform distribution (Facet, Amisys, Xcelys)
  - Classification breakdown (DUAL, Duplicate, COB, Pricing, Auth, etc.)
  - Status distribution (Pending, In Review, Approved, Denied)
- **Loading States**: Displays loading spinner while fetching data
- **Error Handling**: Shows error messages with retry functionality
- **Empty State**: Displays helpful message when no claims data is available
- **Theme Support**: Fully supports light and dark themes

## Usage

Navigate to `/dashboard` to view the dashboard page.

```tsx
// The page is automatically rendered by Next.js App Router
// Access it at: http://localhost:3000/dashboard
```

## Data Source

Currently, the dashboard uses mock data generated by the `generateMockClaims` function from `@/lib/mock-data`. In production, this should be replaced with actual API calls to fetch real claims data.

### Replacing Mock Data with Real API

To connect to a real API, modify the `fetchClaims` function in `app/dashboard/page.tsx`:

```tsx
async function fetchClaims(): Promise<Claim[]> {
  const response = await fetch('/api/claims')
  if (!response.ok) {
    throw new Error('Failed to fetch claims')
  }
  return response.json()
}
```

## Components Used

- **MetricsCard**: Displays individual metrics with icons and optional trend indicators
- **LoadingSpinner**: Shows loading state while data is being fetched
- **ErrorDisplay**: Displays error messages with retry functionality
- **Icons**: Uses Lucide React icons for visual indicators

## Metrics Calculation

The dashboard uses the `calculateDashboardMetrics` function from `@/lib/metrics` to aggregate claims data into meaningful statistics:

- **Total Claims**: Count of all claims
- **Claims by Status**: Count of claims grouped by status (Pending, Approved, Denied, In Review)
- **Claims by Platform**: Count of claims grouped by platform (Facet, Amisys, Xcelys)
- **Claims by Classification**: Count of claims grouped by classification type
- **Total Billed Amount**: Sum of all claim billed amounts
- **Average Billed Amount**: Mean billed amount across all claims
- **Average Days Aged**: Mean days aged for pending claims only

## Performance

- **Auto-refresh**: Data refreshes every 30 seconds using TanStack Query's `refetchInterval`
- **Caching**: Data is cached for 30 seconds (staleTime) to reduce unnecessary API calls
- **Optimized Rendering**: Uses React.useMemo to prevent unnecessary recalculations
